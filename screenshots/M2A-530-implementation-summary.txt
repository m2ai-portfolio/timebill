FEATURE DESCRIPTION:
  Implement project detection that infers the active project from the
  foreground window title, IDE status bar, or browser tab name without
  requiring user input.

KEY COMPONENTS IMPLEMENTED:
  1. ProjectDetector class with detect_from_title() method
  2. Project and TimeEntry dataclass models
  3. Built-in pattern recognition for 25+ applications
  4. Custom pattern support via TIMEBILL_PROJECT_DETECTION env var
  5. GitHub repository name extraction
  6. Comprehensive test suite (18 unit tests)

================================================================================
                          TECHNICAL IMPLEMENTATION
================================================================================

PATTERN MATCHING:
  - Regex-based window title pattern recognition
  - 25+ built-in patterns for common applications
  - Capture groups for dynamic project name extraction (GitHub repos)
  - Case-insensitive matching
  - Custom pattern support via environment variable

DATA MODELS:
  - Standard library dataclasses (no third-party dependencies)
  - Type hints for IDE support
  - Optional fields with sensible defaults
  - Dict metadata field for extensibility

ENVIRONMENT VARIABLE SUPPORT:
  Format: TIMEBILL_PROJECT_DETECTION="pattern1:ProjectName1,pattern2:Name2"
  Example: TIMEBILL_PROJECT_DETECTION="myapp:My App,test:Test Project"
  - Custom patterns override built-in patterns
  - Invalid patterns are silently ignored
  - Supports regex patterns

ERROR HANDLING:
  - Graceful handling of None/empty inputs
  - Returns "Unknown Project" for unmatched titles
  - Fallback to first words of title if no pattern matches
  - Invalid custom patterns don't crash the detector
